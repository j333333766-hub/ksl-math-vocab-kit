# 단계별 구성 가이드

차시 화면 왼쪽의 단계 이름 옆 **TIP** 단추를 누르면 나오는 내용과 같다. 여섯 단계를 어떻게 구성(설계)하는지에 대한 약속이다.

> 모든 단계에 공통: 이 콘텐츠는 학생이 이미 아는 개념을 한국어 낱말로 바꿔 주는 것이다. 문제 풀이 지도, 개념 다시 가르치기, 문법 설명은 하지 않는다. 한 차시는 10분 안팎이고, 지시문의 말투는 60차시 전체에서 한 사람이 쓴 것처럼 맞춘다.

## 1. 도입

**역할** — 이 차시를 왜 보는지 알리고, 필요한 앞 낱말을 아는지 학생이 스스로 고르게 한다.

**이렇게 구성해요**

- 어느 소단원을 배우기 전에 보는 콘텐츠인지, 오늘 익힐 낱말이 무엇인지 한 화면에서 안내한다.
- 선수학습 낱말은 ‘알아요 / 잘 몰라요’로 묻는다. ‘알아요’면 그대로 다음 단계로 넘어가고, ‘잘 몰라요’면 뜻을 한 번 확인하는 화면(또는 그 낱말을 익히는 앞 차시)으로 보낸다.
- 뜻 확인 화면의 보기는 꼭 필요한 낱말만 넣는다(예: 소수, 합성수 두 개).
- 핵심 학습 어휘(충남대 필수 어휘)는 다른 낱말과 색을 달리해 눈에 띄게 한다.

**하지 않아요**

- 선수학습 낱말을 여기서 다시 가르치지 않는다. 아는 학생은 그냥 지나가게 한다.
- ‘~하시오’ 같은 문제에서 쓰는 말은 개념어 차시에 넣지 않는다(공통 차시에서 따로 다룬다).
- 수를 구하거나 계산하게 하지 않는다.

**샘플 차시(소인수분해)에서는** — 소단원 ‘1. 소인수분해’ 안내 → ‘소수’를 알고 있나요?(알아요 / 잘 몰라요) → 잘 몰라요를 고른 학생만 ‘소수 / 합성수’ 확인 화면을 본다.

근거: 10/5 회의: 아는 개념은 넘기고 필요한 것만 학습 · 10/11 회의: 선수학습은 알아요/잘 몰라요, 문제에서 쓰는 말 삭제

## 2. 어휘 제시

**역할** — 오늘의 낱말을 모양과 소리로 처음 만난다. 뜻은 다음 단계(정의)에서 다룬다.

**이렇게 구성해요**

- 한 차시의 학습 어휘는 3개까지로 한다(회의에서 예외로 합의한 차시만 4개).
- 핵심 학습 어휘는 색을 달리해 강조한다.
- 낱말을 누르면 그 낱말을 배우고 싶게 하는 짧은 말이 뜨게 한다(이 낱말을 알면 무엇이 좋은지).
- 두 인물이 나오는 짧은 장면으로 낱말을 처음 보여 준다. “우리 나라 학교에서 배웠어”처럼 이미 아는 개념이라는 점을 대사로 짚는다.
- 낱말의 소리를 들려준다(듣기만 한다).

**하지 않아요**

- 뜻을 길게 설명하지 않는다.
- 따라 쓰기·따라 말하기를 넣지 않는다(연습 단계에서 한다).
- 문제에서 쓰는 말(수행 도구어) 칸을 두지 않는다.

**샘플 차시(소인수분해)에서는** — 오늘의 낱말 ★소인수분해·소인수·거듭제곱 → 낱말을 누르면 응원하는 말 → 수업 장면(아미르·유나) → 낱말 소리 듣기.

근거: 10/5 회의: 한 차시 어휘는 최대 3개, 모두의 한국어와 비슷하게 · 10/11 회의: 쓰고 말하는 것은 연습에서

## 3. 정의

**역할** — 학생이 이미 아는 개념에 한국어 이름을 붙여 준다. 영상을 보여 주고, 뜻을 한 번 떠올리게(리마인드) 하는 데서 끝낸다.

**이렇게 구성해요**

- 글로 길게 설명하지 않고 짧은 영상으로 보여 준다. 영상은 멈추지 않고 이어서 본다.
- 예를 먼저 보여 주고 뜻에 이른다(예: 2는 약수가 1, 2이다. 5는 약수가 1, 5이다. → 2와 5처럼 약수가 1과 자기 자신뿐인 수).
- 뜻풀이는 충남대 자료의 정의를 기본으로 하고, 어려우면 뜻을 해치지 않게 쉬운 한국어로 바꾼다.
- 낱말의 짜임(소수 + 인수 → 소인수)을 보여 주어 낱말로 받아들이게 한다.
- 학습 어휘(또는 그 안의 말)가 ‘분해’, ‘거듭’처럼 일상에서도 쓰는 말이라면, 일상에서 쓰는 용례(예: 블록 집을 분해해요, 자전거를 분해해서 닦아요)를 먼저 보여 주고 그 뜻에서 수학에서의 뜻으로 이어지게 정의한다.
- 영상 뒤에는 낱말 카드를 눌러 뜻을 확인하는 정도만 둔다.
- 학습 어휘가 아닌 곁낱말(예: 밑, 지수)은 그림 이름표로 가볍게만 보여 준다.
- 번역은 설명하는 말에만 쓰고, 수학 낱말은 한국어 그대로 둔다.

**하지 않아요**

- 개념을 다시 가르치지 않는다. 구하는 방법·규칙·증명은 넣지 않는다.
- 컷마다 멈추고 묻지 않는다.
- 쓰거나 말하게 하지 않는다.
- 그림 때문에 오개념이 생기지 않게 한다(예: 블록 분해가 덧셈으로 읽히지 않게 곱셈임을 분명히).

**샘플 차시(소인수분해)에서는** — 낱말 이야기 영상(소인수 = 소수 + 인수, 소인수분해 = 소인수 + 분해, 거듭제곱 = 거듭 + 제곱) → 뜻 카드 3장 → 내 나라 말과 연결.

근거: 오프닝 자료: 문제 풀이 지도·개념 재교수·문법 설명은 하지 않는다 · 10/5 회의: 아는 개념을 한국어로 전환 · 10/11 회의: 정의는 영상 + 리마인드, 밑·지수는 가볍게, 시각 자료 오개념 방지

## 4. 용례

**역할** — 낱말이 실제 문장에서 어떻게 쓰이는지 사례로 보여 준다.

**이렇게 구성해요**

- 용례 문장은 충남대 자료의 용례를 기본으로 쓴다(낱말마다 한 문장 이상. 개수 기준은 학습 어휘 수와 함께 협의 중).
- 문장만 늘어놓지 않고 상황(맥락)을 만든다. 두 인물의 대사가 하나씩 나오고, 용례가 대사 안에 자연스럽게 들어가게 한다.
- 한 차시의 학습 어휘들이 서로 어떻게 이어지는지가 대화의 순서로 드러나게 한다(예: 소인수를 찾고 → 곱으로 쓰면 소인수분해 → 같은 수의 곱은 거듭제곱).
- ‘~의 소인수’, ‘~을 소인수분해하면’처럼 함께 쓰이는 말이 보이게 한다.
- 끝에 낱말을 잘못 쓴 문장을 찾는 화면을 둘 수 있다. 수학 내용이 틀린 문장이 아니라 낱말만 바꿔 쓴 문장을 넣는다.

**하지 않아요**

- 수학 문제를 풀게 하지 않는다.
- 쓰거나 말하게 하지 않는다(연습 단계에서 한다).
- 문법을 설명하지 않는다.

**샘플 차시(소인수분해)에서는** — 발표를 준비하는 아미르와 돕는 유나의 대화 13마디(용례 3문장은 색이 다른 말풍선) → 잘못 쓴 문장 2개 찾기.

근거: 10/11 회의: 용례는 사례를 보여 주는 것, 충남대 어휘 사전의 용례를 소개 · 대화로 구성하고 잘못 쓴 문장 찾기를 두는 방식은 10/11 조창현 제안(연구진 확인 전)

## 5. 연습

**역할** — 낱말을 직접 고르고, 쓰고, 말해 본다. 쓰고 말하는 활동은 모두 이 단계에 모은다.

**이렇게 구성해요**

- 순서: 낱말 고르기 → 듣고 쓰기(자판) → 손글씨로 따라 쓰기 → 듣고 따라 말하기 → 받아쓰기.
- 고르기 문항은 “이런 것을 무엇이라고 할까요?”처럼 묻고, 보기는 오늘 익힌 낱말만 넣는다.
- 식과 그림은 이미 풀린 채로 보여 주고, 답은 언제나 낱말이 되게 한다.
- 수학 수업이 아니라 한국어 수업처럼 느껴지게 구성한다.
- 말하기는 음성 인식과 캐릭터의 짧은 대답을 붙일 수 있는지 업체와 협의한다.

**하지 않아요**

- 수를 구하거나 계산하는 문항을 넣지 않는다.
- 답이 수가 되는 문항을 넣지 않는다.
- 틀렸다는 표시나 점수를 앞세우지 않는다.

**샘플 차시(소인수분해)에서는** — 고르기 3 → 듣고 쓰기 → 손글씨 3 → 따라 말하기 3 → 받아쓰기.

근거: 10/6 김수철 교수: 수학 문제 풀이 형식은 다른 형식으로 · 10/11 회의: 쓰고 말하는 것은 연습에서, 손글씨로 따라 쓰기, 한국어 콘텐츠 같은 느낌

## 6. 마무리

**역할** — 오늘 익힌 낱말을 한눈에 다시 보고 스스로 점검하며 가볍게 끝낸다.

**이렇게 구성해요**

- ‘점검해 봐요’ 한 화면, 또는 짧은 정리 영상 하나로 끝낸다.
- 낱말·뜻·예를 한 화면에 요약해 보여 준다.
- ‘알아요 / 다시 볼래요’로 스스로 점검하게 하고, ‘다시 볼래요’면 정의 영상에서 그 낱말이 나오는 곳으로 돌아가게 한다.
- 학교 수업에서 이 낱말을 만난다는 한마디로 맺는다.

**하지 않아요**

- 문제 풀이로 끝내지 않는다.
- 새 낱말이나 새 내용을 넣지 않는다.
- 점수를 매기지 않는다.

**샘플 차시(소인수분해)에서는** — 소인수·소인수분해·거듭제곱의 뜻과 예 → 알아요 / 다시 볼래요.

근거: 10/11 회의: 마무리는 점검해 봐요 한 페이지 또는 간단한 영상 하나, 문제 풀이가 아닌 핵심 어휘 요약 정리
